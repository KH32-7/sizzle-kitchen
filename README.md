# 지글지글 키친 (Sizzle Kitchen)

브라우저에서 바로 하는 요리 시뮬레이션 게임. 썰고, 볶고, 삶고, 부쳐서 손님 주문을 처리하고 식당을 운영해요.

- 15가지 레시피: 기본(김치볶음밥·계란볶음밥), 면 요리 팩, 전 팩, 일본 요리 팩, 양식 팩
- 주문·돈·평판·영업일 정산, 냉장고와 장보기
- 팬 온도, 수분 증발, 면 삶기와 끓어 넘침, 스테이크 심부 온도, 퍼지는 액체까지 시뮬레이션

**플레이:** https://kh32-7.github.io/sizzle-kitchen/

단일 HTML 파일이라 `index.html`을 내려받아 열어도 돼요.
